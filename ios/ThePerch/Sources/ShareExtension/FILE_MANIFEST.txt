SUPABASE TABLES
================================================================================

TABLE: bookmarks
├── id (UUID) primary key
├── user_id (UUID) foreign key → auth.users
├── url (TEXT) - the bookmarked URL
├── title (TEXT) - page title
├── domain (TEXT) - extracted domain
├── tags (TEXT[]) - tag array
├── status (TEXT) - 'pending' or 'processed'
├── created_at (TIMESTAMPTZ)
└── updated_at (TIMESTAMPTZ)

TABLE: records
├── id (UUID) primary key
├── user_id (UUID) foreign key → auth.users
├── bookmark_id (UUID) foreign key → bookmarks
├── type (TEXT) - 'bookmark'
├── category (TEXT) - 'bookmarks'
├── display_hint (TEXT) - 'bookmark_card'
├── metadata (JSONB) - {url, title, tags}
├── created_at (TIMESTAMPTZ)
└── updated_at (TIMESTAMPTZ)

UI FLOW
================================================================================

1. User taps Share button → selects "Save to The Perch"
2. ShareViewController extracts URL & title from NSExtensionItem
3. ShareExtensionView shows:
   - Domain/favicon circle (placeholder, customize for Fabio)
   - Page title
   - Full URL (truncated)
   - Optional tags input field (comma-separated)
   - Save button (prominent blue)
   - Cancel button (secondary)
4. User can add tags or leave blank
5. User taps "Save"
6. Loading spinner appears in Save button
7. ShareSupabaseClient:
   - Reads credentials from shared App Group
   - Inserts row in bookmarks table (status='pending')
   - Inserts row in records table (type='bookmark')
8. Success! Green checkmark animation
9. Auto-dismiss after 1.5 seconds
10. Extension closes, returns to Share source app

================================================================================
ERROR CASES
================================================================================

Missing Credentials
├── No Supabase URL in shared UserDefaults
├── No Supabase anon key in shared UserDefaults
└── No auth token in shared Keychain
    → Show "Missing credentials" error
    → Auto-dismiss, user must login in main app

Network Error
├── No internet connection
├── Request timeout
├── DNS resolution failure
    → Show "Network error" message
    → Offer retry option

Server Error
├── 400 Bad Request - Invalid payload
├── 401 Unauthorized - Token expired
├── 403 Forbidden - Insufficient permissions
├── 500 Server Error - Database error
    → Show "Server error (XXX): details"
    → Check Supabase dashboard

Decoding Error
├── Invalid JSON response
├── Missing required fields
    → Show "Failed to parse response"
    → Log for debugging

TROUBLESHOOTING REFERENCE
================================================================================

Extension doesn't appear in Share menu:
→ Check App Groups entitlement
→ Verify NSExtension in Info.plist
→ Check bundle ID and signing
→ Restart simulator/device

"Missing credentials" error:
→ Main app must call storeSharedSupabaseCredentials()
→ Verify UserDefaults and Keychain are accessible
→ Check App Group identifier matches

Auth token expired:
→ Main app should refresh token periodically
→ Logout and login to get fresh token
→ Consider implementing token refresh flow

Memory warning:
→ Profile with Xcode Instruments
→ Check for retain cycles in ShareExtensionView
→ Verify URLSession is being reused

================================================================================
DEVELOPER NOTES
================================================================================

Architecture Principles:
- Minimal dependencies (Foundation + SwiftUI only)
- Direct URLSession for API calls (no SDK)
- Async/await for modern Swift concurrency
- Keychain for secure credential storage
- App Groups for inter-app communication

Code Style:
- Follows Swift naming conventions
- Clear separation of concerns
- Error handling with custom enums
- Comments on complex logic
- TODO markers for future customization

Security:
- Auth tokens in Keychain (not UserDefaults)
- App Group scoping for shared access
- No sensitive data in logs
- URLs validated before storage
- Proper error messages (no technical details exposed to user)

Performance:
- URLSession reuses connections
- Minimal JSON parsing (only error responses)
- No network requests on main thread
- SwiftUI updates on correct thread (MainActor)

Extensibility:
- ShareSupabaseClient can be extended for other operations
- KeychainHelper can be reused for other credentials
- UI is easy to customize in ShareExtensionView
