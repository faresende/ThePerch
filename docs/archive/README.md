# Archive

Historical design reviews, plans, and audits from The Perch's development. Kept for reference and context, but not part of the current onboarding flow.

If you're new to the repo, start with [README.md](../../README.md) and [SHARE.md](../../SHARE.md) at the root instead.

## Contents

| File | What it is |
|---|---|
| `DESIGN_REVIEW.md`, `DESIGN_REVIEW_V2.md` | Early design-review notes from the iOS app's foundation phase |
| `FILE_MANIFEST.md` | Snapshot of repo structure at an earlier point; may be stale |
| `FOUNDATION_SUMMARY.md`, `IMPLEMENTATION_CHECKLIST.md` | Build notes from the foundation milestone |
| `HOME_REDESIGN.md` | The home-tab redesign spec |
| `PERF_REVIEW.md`, `PERFORMANCE_AUDIT.md` | Performance review notes |
| `PLAN.md`, `PLAN_M2.md` | Milestone plans |
| `PRODUCT_REVIEW.md`, `SWE_REVIEW.md` | Reviews from different angles |
| `WORKLOG.md` | Running work log |

These files mention specific historical decisions and are often tied to Fábio's personal setup. They are preserved for anyone who wants to understand how we got here; they are not intended as instructions for new users.
