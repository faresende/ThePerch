private phase. Some shipped (Travel, capture v1, time-aware insights),
some didn't, some shipped under different names. They reference the
maintainer's personal agent stack and old paths and are NOT a useful
guide for new contributors.

For current architecture, start with [SETUP-FOR-AGENTS.md](../../../SETUP-FOR-AGENTS.md)
and [docs/agent-integration.md](../../agent-integration.md).
