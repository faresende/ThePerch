QUICK INTEGRATION (7 Steps)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Create ShareExtension target in Xcode
   File → New → Target → App Extension → Share Extension

2. Add all .swift files to the project
   - Add to ShareExtension target membership

3. Configure entitlements
   - Add App Group: group.com.theperch.shared
   - Add Keychain access group: $(AppIdentifierPrefix)group.com.theperch.shared

4. Update Info.plist
   Copy NSExtension configuration from SETUP.md

5. Integrate main app (use MainAppIntegration.swift)
   - Call storeSharedSupabaseCredentials() on login
   - Call clearSharedSupabaseCredentials() on logout

6. Create Supabase tables
   - Copy SQL from SETUP.md
   - Create bookmarks and records tables

7. Test!
   - Build ShareExtension scheme
   - Test from Safari → Share → The Perch

HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. User taps Share → selects "Save to The Perch"
2. ShareViewController extracts URL & title from the shared app
3. ShareExtensionView shows a compact form with:
   - Domain/favicon placeholder (ready for customization)
   - Page title
   - Full URL
   - Optional tags input (comma-separated)
4. User adds tags (optional) and taps Save
5. ShareSupabaseClient reads credentials from shared App Group
6. Two records are created:
   - bookmarks table: { url, title, domain, tags, status='pending' }
   - records table: { bookmark_id, type='bookmark', metadata={...} }
7. Green checkmark animation appears
8. Extension auto-dismisses after 1.5 seconds

DATA SAVED TO SUPABASE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BOOKMARKS TABLE:
  - id: UUID (auto-generated)
  - url: The bookmarked URL
  - title: Page title or domain
  - domain: Extracted domain
  - tags: Array of tags (user-provided)
  - status: 'pending' (for processing)
  - created_at: Timestamp

RECORDS TABLE:
  - id: UUID (auto-generated)
  - bookmark_id: Links to bookmarks row
  - type: 'bookmark'
  - category: 'bookmarks'
  - display_hint: 'bookmark_card'
  - metadata: JSON with {url, title, tags}
  - created_at: Timestamp
