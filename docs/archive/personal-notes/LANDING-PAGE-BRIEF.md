# Landing Page Brief — for Claudinho

> Build a landing page for The Perch. Single page, scrollable. Editorial Linen aesthetic — same calm serif italic / muted color language the iOS app uses. No SaaS-style "Get Started Free" gradient buttons. This is a personal-project landing page that respects the visitor's intelligence.

## One-line pitch

**A personal life dashboard for iOS, powered by small agents you run yourself.**

Not a service. Not a subscription. A piece of software that lives on your phone and your machine, talks to your existing accounts (Withings, 8sleep, Karakeep, Fastmail), and renders the things you actually look at every day in a tone that doesn't sound like a fitness watch.

## What it does (3 columns or rows)

### 1. Reads your data, writes nothing without permission

The iOS app is read-only against Supabase. Everything that puts data in front of you is written by an agent on your machine — your Mac, not someone else's cloud. If the agent stops running, no data is sent anywhere; you just stop getting updates.

### 2. Knows the difference between data and information

> *"Sleep dropped to less than half what you usually pull. Protein's lagged target two days running. Body's finally got something to say about the load."*

That's a real BioChecha card from this morning — generated by an LLM running against your real numbers, written in 50 words instead of a wall of charts. The Perch doesn't show you everything; it shows you what's worth noticing.

### 3. Talks to the services you already pay for

| Source | What it pulls |
|---|---|
| 8sleep | Nightly sleep stages, HRV, RHR, room/bed temp |
| Withings | Weight, body fat %, lean mass, hydration |
| Fastmail JMAP | Order confirmations, shipping notifications |
| 17track | Carrier ETAs across DHL, UPS, FedEx, USPS, etc. |
| Karakeep | Self-hosted bookmarks (optional) |
| OpenAI | Daily insight generation (gpt-4o-mini, ~$0.0001/day) |

Each integration is independent. Skip the ones you don't have. The app degrades to empty states for missing sources.

## Five things the app does well

1. **Order tracking that doesn't lie.** Inbox scanner classifies email by tier-1 keyword regex → tier-2 LLM → tier-3 learned-senders. Tracking-candidate priority-rank-wins (carrier-owned URLs > body regex). Every parser decision recorded in a `parse_trace` JSONB so you can long-press any order to see "why was this classified as an order?"

2. **Daily insight in your voice.** BioChecha pulls from sleep + nutrition + body composition + workouts. Writes one tight paragraph (30-55 words). Comparative over absolute ("less than half" beats "190 minutes"). Cross-domain by default. No coaching, no recommendations dressed as recommendations, no "consider taking" or "remember to."

3. **Corrections-and-rules feedback loop.** When you long-press an order and tap "Not an order" / "Wrong tracking" / "Already delivered", the app writes a correction row with a snapshot of the parse_trace — the exact reasoning the parser used. Phase 2 (after a month of corrections data) distills these into merchant rules that pre-empt future misclassifications.

4. **Editorial Linen design system.** Serif italic body type for things that read like writing; monospace for numbers; muted palette that shifts with time of day. Cards stack stably (no time-of-day shuffling). Liquid Glass tab bar on iOS 26.

5. **Self-hostable and forkable.** Source MIT, every integration documented, install instructions in 14 steps with an `SETUP-FOR-AGENTS.md` file you can hand to an LLM agent to do the whole thing.

## FAQ (sample copy — keep most of these)

**Is this a service I can sign up for?**
No. It's source code. You run it on your own Mac, against your own Supabase project, with your own integrations. There's nothing to subscribe to.

**How much does it cost to run?**
Supabase free tier: $0. OpenAI gpt-4o-mini for daily insights: ~$0.03/month. 17track free tier: 0 (sufficient for ~5 active shipments). Withings developer account: 0. Karakeep self-host: ~$2/month if you put it on a tiny VPS, or $0 if you skip the integration.

**Is this Android-friendly?**
No. iOS-only. Sorry.

**What if 8sleep changes their API?**
The 8sleep integration is reverse-engineered (no public API). When they ship a new app version that breaks it, the integration will go dark until someone (probably me) catches up. The rest of The Perch keeps working without it.

**Can you make a hosted version?**
That's not the project. Self-hosted by design.

**Do you accept contributions?**
For bug fixes and small features, yes. For anything bigger than a single file, open an issue first so we can talk about the shape.

## What NOT to put on the page

- A pricing table. There is no pricing.
- "Trusted by N teams." It's a personal project.
- Testimonials. From whom?
- A waitlist signup. The repo is the signup.
- "Used by Y employees at Z companies."
- Login / signup buttons. The product is on GitHub.
- Animated illustrations of brain icons or graphs.
- Any phrase that begins with "Imagine if…"
